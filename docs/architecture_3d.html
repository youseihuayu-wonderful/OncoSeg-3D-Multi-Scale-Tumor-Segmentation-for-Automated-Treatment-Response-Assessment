Deep Dive: Cross-Attention
Cross-Attention Skip — a full walk-through

We trace one volume through the whole network, then zoom into a single cross-attention skip and compute it by hand on a tiny worked example. Every number below is the real result of the math — nothing is faked.

1 The whole forward pass, by shape

Take one MRI patch: x = [B=1, C=4, 128, 128, 128] (T1, T1c, T2, FLAIR). The Swin encoder shrinks space while growing channels; the CNN decoder does the reverse, pulling encoder features back in through cross-attention skips.

StageOutput shapeWhat happens
Input[1, 4, 128³]4 MRI modalities stacked as channels
Patch-embed + Swin Stage 1[1, 48, 32³]4×4×4 patches ↓4 · window self-attention
Swin Stage 2[1, 96, 16³]patch-merge ↓2, channels ×2
Swin Stage 3[1, 192, 8³]depth-6 attention (richest semantics)
Swin Stage 4 — bottleneck[1, 384, 4³]most abstract global features
Decoder Block 1  ⟵ x-attn skip ⟵ Stage 3[1, 192, 8³]ConvT3d ↑2, fuse Stage-3 features
Decoder Block 2  ⟵ x-attn skip ⟵ Stage 2[1, 96, 16³]ConvT3d ↑2, fuse Stage-2 features
Decoder Block 3  ⟵ x-attn skip ⟵ Stage 1[1, 48, 32³]ConvT3d ↑2, fuse Stage-1 features
Upsample head[1, 48, 128³]ConvT3d ↑4 recovers the patch-embed downsample
Final 1×1×1 conv[1, 3, 128³]TC / WT / ET sigmoid logits

The three ⟵ x-attn skip rows are the only place encoder and decoder talk. We now open one of them.

2 One skip, at real scale (Decoder Block 1)

This skip fuses Swin Stage 3 (encoder) into Decoder Block 1. After the decoder upsamples to 8³, both tensors live on an 8×8×8 grid, so each has N = 512 voxels (tokens), each a 192-dim vector, split across 12 heads (head_dim = 16). The module is a drop-in replacement for the usual x + skip:

# src/models/modules/cnn_decoder.py — DecoderBlock.forward
x = self.upsample(x)                        # [1,192,8³] decoder side
if cross_attn is not None:
    x = cross_attn(encoder_feat=skip,        # Stage-3 [1,192,8³] → Key/Value
                   decoder_feat=x)           # decoder    [1,192,8³] → Query
else:
    x = x + skip                             # the plain U-Net fallback (ablation: no_xattn)
x = self.conv(x)

1

Flatten to tokens

encoder_feat.flatten(2).transpose(1,2) turns [B,C,H,W,D] into a sequence [B, N, C]. Each voxel becomes one token. Here N=3 (encoder) and N=2 (decoder).

2

LayerNorm each side separately

norm_enc and norm_dec are two different norms — because Swin (attention space) and CNN (conv space) features have different scales/statistics. Normalising each first puts them on comparable footing before the dot product. (Omitted numerically here so the multiplication stays readable.)

3

Project: Q from decoder, K & V from encoder

q_proj(decoder), k_proj(encoder), v_proj(encoder). The decoder asks the questions; the encoder supplies both the "match keys" and the "content to return". With identity projections, Q = decoder tokens, K = V = encoder tokens.

4

Similarity: scores = Q·Kᵀ × scale

scale = 1/√head_dim = 1/√4 = 0.5, which keeps the dot products from blowing up. Row = a decoder voxel, column = an encoder region.

scores (2×3)
4.3751.6250.050← qA vs (e1,e2,e3)
1.5003.5001.700← qB vs (e1,e2,e3)

qA's biggest score (4.375) is against e1 tumor-core — exactly the region it resembles. qB peaks (3.500) on e2 edema.

5

Softmax → attention weights

attn.softmax(dim=-1) turns each row into a probability distribution over encoder regions — "how much of each to pull".

weights — qA
92.8%5.9%1.2%
weights — qB
10.4%76.9%12.7%

qA pulls 92.8% from tumor-core; qB is a blend dominated by edema (76.9%). The decoder retrieves selectively, not the whole encoder map.

6

Weighted sum: out = weights · V

Each decoder voxel gets a new 4-ch feature = its attention-weighted mix of the encoder Value rows.

out (2×4)
2.8150.6450.9580.067← qA ≈ e1 core
0.6972.3840.4880.766← qB ≈ e2 edema

qA's output ≈ the tumor-core vector [3,0.5,1,0] — it successfully fetched the right high-level evidence to sharpen that voxel.

7

Residual on the decoder side + FFN

out = dec_seq + out then out = out + ffn(norm_out(out)). The residual is anchored on the decoder, so cross-attention is an additive refinement, never a replacement — if attention learns nothing, the decoder trunk survives, and the module degrades gracefully to a plain skip.

decoder + out (pre-FFN)
5.3151.1451.9580.067
1.1974.3840.9881.766
8

Reshape back to a volume

out.transpose(1,2).reshape(B, C_dec, H, W, D) folds the tokens back into an 8×8×8×192 feature map, which the next Conv3d·InstanceNorm·LeakyReLU refines. Shape in == shape out, so it slots straight into the U-Net.

Why this beats plain x + skip: concatenation forces the decoder to swallow the entire encoder map and sort it out later. Cross-attention lets each decoder voxel ask for exactly the encoder evidence it needs — qA grabbed tumor-core, qB grabbed edema — bridging the semantic gap between Swin's global features and the CNN's local geometry. The cost: attention is O(N²) over voxels, which is why the encoder itself stays windowed and the ablation no_xattn exists to prove the trade is worth it.

Why build it this way?

hover a card →
–

Asymmetric hybridall blocks

Segmentation needs both global context and pixel-precise boundaries. One family of layers can't do both cheaply, so OncoSeg splits the job: Transformer encodes, CNN decodes.

Swin encoder = global contextencoder ↓

A tumour voxel's label depends on far-away anatomy. Self-attention is global by construction; shifted windows keep 3D attention memory-feasible. 4 hierarchical stages give the multi-scale features a U-Net needs.

CNN decoder = local detaildecoder ↑

Output must return to full resolution. Transposed convs rebuild smooth boundaries and are parameter/memory-efficient. Attention here would explode (tokens = H·W·D), so CNN is the right tool for dense reconstruction.

Cross-attention skipsthe twist

Plain U-Nets just concatenate skips. Here the decoder queries the encoder (Q=decoder, K/V=encoder), pulling only the relevant cues — this aligns Swin's semantics with the CNN's geometry. Ablated by no_xattn.

Bottleneck + temporalstage 4

The deepest stage holds the most abstract global features. Optional temporal attention fuses baseline ↔ follow-up here, so the same backbone supports longitudinal response tracking.

Heads: deep-sup · MC-dropout · RECISToutput

Deep supervision adds gradient signal to decoder stages during training; MC-Dropout turns one model into an uncertainty estimator (ECE 0.010); the mask drives RECIST → CR/PR/SD/PD.

Why each module — the physical meaning

The whole network imitates how a radiologist reads a scan: first understand the image from local detail up to the whole lesion (encode), then paint that understanding back into a precise per-voxel mask (decode), looking back at the original detail along the way (skips). Here is what every block physically means, and why it is built that way.

🩻 Input — give the model the evidence
4-modal MRI[1, 4, 128³]input
PHYSICALFour MRI sequences are four filters on the same brain: T1c lights up enhancing tumor (broken blood–brain barrier), T2/FLAIR light up edema, and so on. Stacked as 4 channels, the model sees the anatomy from four angles at once.
WHYA single sequence is ambiguous; cross-referencing all four is how a radiologist tells tumor from vessel from swelling. Channels are the cheapest way to fuse them from layer one.
WITHOUT ITWith one sequence, enhancing tumor and edema look alike — the model confuses tissue types and mislabels region boundaries.
Patch Embed (4×4×4)↓4 → [1, 48, 32³]stem
PHYSICALChop the volume into little 4×4×4 sugar cubes and summarise each cube into one feature vector — a "super-voxel" digest of the raw scan.
WHYRunning attention on 128³ raw voxels is impossibly expensive. Downsampling ×4 first makes everything downstream tractable while keeping local texture.
WITHOUT ITAttention would run on millions of raw voxels — memory explodes and the model simply won't fit on a GPU.
🧠 Swin encoder — understand: look wider, abstract more
Window + shifted-window self-attentionencoder
PHYSICALDeciding "is this voxel tumor?" depends on far-away anatomy. Self-attention lets each location look around globally; the window limits looking to a neighbourhood, and the next layer shifts the windows so neighbourhoods exchange news.
WHYFull 3D global attention would blow up memory. Windowing + shifting is "affordable global vision" — most of the context, a fraction of the cost.
WITHOUT ITPlain global 3D attention is O(N²) over millions of voxels — infeasible. Drop attention for pure convs and you lose the long-range context that tells tumor from look-alike.
4 hierarchical stages (↓ space, ↑ channels)48→96→192→384encoder
PHYSICALEach stage steps back to see more: half the resolution, double the semantic vocabulary. Shallow stages read edges/texture; deep stages read whole-lesion structure — like zooming from "a grey speck" out to "a mass with surrounding edema".
WHYSegmentation needs features at many scales. A hierarchy hands the decoder a ready-made multi-scale pyramid to reconstruct from.
WITHOUT ITA single-scale encoder gives the decoder nothing to fuse — coarse masks that handle neither tiny enhancing foci nor large whole-tumor extent well.
🎯 Bottleneck — the most compressed judgement
Swin Stage 4 — bottleneck[1, 384, 4³]bottleneck
PHYSICALThe whole scan squeezed into a tiny, maximally semantic blob — "what the tumor is and roughly where", with almost no precise outline left. The model's highest-level understanding.
WHYIt is the information-dense pivot of the U. Because it is the most meaningful representation, it is also where uncertainty (MC-Dropout) and longitudinal change are best measured.
WITHOUT ITNo compressed global representation means the network never forms a holistic "what & where" — segmentation stays locally myopic and inconsistent across the lesion.
Temporal attention (optional)bottleneck
PHYSICALAt this abstract level, align baseline ↔ follow-up scans and read off what changed — did the tumor grow or shrink?
WHYChange should be judged in the understanding space, not by subtracting pixels (too noisy). Same backbone, now supporting longitudinal response tracking.
WITHOUT ITEach scan is judged in isolation — response has to be inferred afterward from noisy raw-pixel differences, which drift with registration error and intensity shifts.
🖌️ CNN decoder — localize: paint precise boundaries
Transposed-conv upsampling blocks↑2 each · 192→96→48decoder
PHYSICALThe bottleneck knows "there is a tumor" but the edges are blurry. Each block enlarges and re-inks the outline, recovering detail one level at a time.
WHYConvolution is built for local, smooth, continuous boundaries and is memory-cheap at high resolution — attention here would explode (tokens = H·W·D). Right tool for dense reconstruction.
WITHOUT ITNo path back to full resolution — the output is stuck at the 1/32-size bottleneck grid, with no per-voxel mask to show.
Cross-attention skipencoder ↔ decoder
PHYSICALWhile re-inking, the decoder looks back at the original scan and asks "remind me of the sharp detail here" — but it retrieves selectively, pulling only the relevant encoder evidence, not the whole map.
WHYIt bridges abstract understanding (Swin) with precise geometry (CNN) — the semantic gap a plain concat skip can't close. (See the Deep Dive tab for the hand-worked example.)
WITHOUT ITFalls back to concat/add (the no_xattn ablation): mismatched encoder/decoder features inject noise, boundaries blur, and Dice measurably drops.
⚕️ Heads — supervise, quantify uncertainty, decide
Deep supervisiontraining
PHYSICALGrade the work at every zoom level, not just the final mask — a segmentation head on multiple decoder scales.
WHYFeeds gradient directly into intermediate layers so deep stages don't drift; faster, more stable convergence.
WITHOUT ITOnly the final layer gets a direct training signal — deep stages learn slower and can drift, giving weaker intermediate features and shakier convergence.
MC Dropoutinference
PHYSICALMake the model "think it through N times" with neurons randomly dropped each pass. The more the predictions disagree, the less sure it is — usually most uncertain at tumor margins.
WHYTurns one model into one that flags where it is unsure for human review. Calibrated here to ECE 0.010 — the doubt is trustworthy.
WITHOUT ITA single point prediction with no confidence — the model fails silently at ambiguous margins, and nothing tells a clinician where to double-check.
Output: 3× sigmoid (TC / WT / ET)[1, 3, 128³]output
PHYSICALThe BraTS tumor is three nested sub-regions (enhancing ⊂ core ⊂ whole). One voxel can belong to several at once, so each region is an independent yes/no.
WHYSigmoid (multi-label), not softmax — softmax forces mutually-exclusive classes, which would be clinically wrong for nested regions.
WITHOUT ITUse softmax and a voxel can't be both ET and TC at once — the nested-region structure is broken and the labels become clinically invalid.
RECIST → response (CR / PR / SD / PD)clinical
PHYSICALMeasure the tumor, compare to the prior scan, and classify treatment response — complete / partial response, stable, or progression.
WHYTurns a segmentation mask into a decision a clinician can act on — the endpoint that makes the whole pipeline useful.
WITHOUT ITYou produce a mask but no decision — the pipeline stops one step short of anything a trial workflow can actually use.
So why "U-shape + asymmetric hybrid"? The left arm understands → needs global view → Transformer. The right arm localizes → needs sharp boundaries → CNN. The skips return the detail lost while understanding, and cross-attention makes that return on-demand rather than a blind concat. Understanding and localizing are different jobs, so the network uses the right tool on each side — that is the core trade-off of the design.
